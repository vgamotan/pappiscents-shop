# PappiScents.shop

Static one-page storefront for Pappi Suds & Scents. It uses plain HTML, CSS, and a small amount of vanilla JavaScript—no build step or external framework required.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload the contents of this folder to its root.
2. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
3. In **Settings → Pages → Custom domain**, enter `pappiscents.shop` and enable HTTPS after DNS validation succeeds.
4. At your domain registrar, add GitHub Pages' current DNS records for the apex domain and add `www` as a CNAME to your GitHub Pages hostname if you want the `www` address too.

## Before launch

- Set up the `orders@pappiscents.shop` mailbox or change that address near the bottom of `index.html`.
- Verify the Shopee shop URL (`https://shopee.ph/bilyotoy`) and update it if your public shop link differs.
- Confirm current product availability, prices, and delivery timing before promotion.
